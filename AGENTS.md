# SigfoxTagPrep — Agent Guide

This document describes the project for AI coding agents. It reflects the repository as of the latest exploration; when in doubt, verify against the actual files rather than assuming this guide is exhaustive.

## Project overview

SigfoxTagPrep is an **R package** for downloading, processing, and analysing wildlife tracking data from ICARUS/Sigfox biologger tags (TinyFox, NanoFox, uWasp). The package covers the full pipeline from raw Wildcloud exports or Movebank downloads to analysis-ready `move2` objects, including movement metrics, VeDBA activity scaling corrections, barometric altitude conversion, ERA5 weather annotation, tag fall-off detection, and nocturnal migration bout identification.

- **Package name:** `SigfoxTagPrep`
- **Version:** `0.1.0` (from `DESCRIPTION`)
- **Author/maintainer:** Edward Hurme
- **Repository:** https://github.com/ehurme/SigfoxTagPrep

## Technology stack

- **Primary language:** R (>= 4.1.0)
- **Package framework:** Standard R package using `roxygen2` for documentation and `devtools` for development
- **Core R dependencies:** `move2`, `sf`, `dplyr`, `lubridate`, `ggplot2`, `rvest`, `suncalc`, `janitor`, `data.table`, `mapview`, `rnaturalearth`, `stringr`
- **Optional R dependencies:** `terra` (ERA5 raster extraction), `moonlit` (GitHub-only moonlight covariates), `elevatr` (ground elevation), `geosphere`, `lme4`, `cmdstanr`/`posterior` (Bayesian HMMs), `testthat` (>= 3.0.0)
- **Python:** Used only for ERA5 data download and animation (`python/` directory)
  - Key packages: `cdsapi`, `xarray`, `netCDF4`, `cfgrib`, `numpy`, `pandas`, `matplotlib`, `cartopy`, `Pillow`, `tqdm`
  - `ffmpeg` is required separately for `.mp4` output
- **Documentation:** R Markdown vignettes/notebooks (`example.Rmd`, `wildcloud_to_movebank_guide.Rmd`)

### Important path notes

- The Python helpers live in `python/`, **not** `inst/python/`.
- Retired functions, Bayesian HMM scripts (with their Stan files) and site-specific runs were moved to the sibling `ExploreTinyFox` repo (`old/SigfoxTagPrep/`, `R/Migration/bayesian/`, `explore/sigfoxtagprep_runs/`).
- `explore/` contains site-specific and scratch scripts; do not treat them as part of the exported package API.
- `claude/` holds design and review notes but is not a formal vignette directory.

## Build and test commands

### Standard R package workflow

```r
# Load all package code without installing
devtools::load_all()

# Generate documentation from roxygen comments
devtools::document()

# Run the test suite
devtools::test()

# Run R CMD check (the CI command)
rcmdcheck::rcmdcheck(args = "--no-manual", error_on = "error")
```

### Command-line equivalents

```bash
Rscript -e "devtools::document()"
Rscript -e "devtools::test()"
Rscript -e "rcmdcheck::rcmdcheck(args = '--no-manual', error_on = 'error')"
```

### Python helpers

Install Python dependencies first:

```bash
pip install -r python/requirements.txt
```

Download ERA5 data:

```bash
python python/download_era5.py python/era5_config.json
python python/download_era5.py python/era5_config.json --dataset single
python python/download_era5.py python/era5_config.json --dataset pressure
```

A valid `~/.cdsapirc` or CDS environment credentials are required.

## Code style and conventions

- **Indentation:** RStudio project uses 2 spaces, tabs converted to spaces (`UseSpacesForTab: Yes`, `NumSpacesForTab: 2`).
- **Line endings:** POSIX (`LineEndingConversion: Posix`), `AutoAppendNewline: Yes`, `StripTrailingWhitespace: Yes`.
- **Encoding:** UTF-8.
- **Documentation style:** `roxygen2` with Markdown enabled (`Roxygen: list(markdown = TRUE)`). Use `@export` for public functions and `@examples \dontrun{...}` for anything requiring network/data.
- **Naming:** functions are `snake_case`; columns and variables are also generally `snake_case`.
- **Internal helpers:** Functions not exported are often prefixed with `.` (e.g. `.correct_vedba_scaling()` in `import_nanofox_movebank.R`).
- **Package-loading pattern:** Many functions call `pacman::p_load(...)` to ensure runtime dependencies are installed. This is unusual for a published R package but is the established convention here; preserve it unless you are deliberately refactoring.
- **Cross-file sourcing:** Several workflow scripts in `explore/` and some functions use `source("R/xxx.R")` to load helpers. Be cautious when moving files because paths are often hard-coded relative to the project root.
- **Column-name conventions:**
  - Movement: `distance`, `diff_time`, `bearing`, `displacement`, `climb_rate_ms`
  - Activity: `vedba`, `vedba_sum`, `*_orig` for pre-correction values
  - Weather: `era5_*` prefix for ERA5 variables, `wind_support_*`, `crosswind_*`, `airspeed_*`
  - Tag metadata: `individual_local_identifier`, `tag_type`, `tag_firmware`

## Testing instructions

- The package uses **testthat edition 3** (`Config/testthat/edition: 3`).
- Tests live in `tests/testthat/`; `tests/testthat.R` is the standard entry point.
- Tests are offline unit tests of pure helpers (start-row placement, tag-type override, VeDBA scaling, conversions, night-date keys) built on small `move2` fixtures in `helper-move2.R`. They do not hit Movebank, so changes to the download pipeline must still be validated on real data.
- The GitHub Actions workflow runs `rcmdcheck::rcmdcheck(args = "--no-manual", error_on = "error")` on R 4.1.1.

## Continuous integration and deployment

- GitHub Actions workflow: `.github/workflows/r.yml`
- Triggered on pushes and pull requests to `main`.
- Matrix: single R version (`4.1.1`) on `ubuntu-latest`.
- Steps: checkout, set up R, install `remotes` and `rcmdcheck`, install package dependencies with `remotes::install_deps(dependencies = TRUE)`, run `R CMD check --no-manual`.
- There is no automated deployment to CRAN or GitHub Releases; installation is via `devtools::install_github("ehurme/SigfoxTagPrep")`.

## Security and environment considerations

- The legacy `sigfox_download()` function scrapes the MPIAB Sigfox web database with `rvest`. It is currently functional only for NanoFox tags and is considered legacy; new data should come from Wildcloud/Movebank.
- ERA5 downloads require Copernicus CDS credentials. Never commit API keys or `~/.cdsapirc` content to the repository.
- The project references network paths (e.g. `//10.0.16.7/grpdechmann/Postdoc-EdwardHurme/EnvData`) in scripts and configuration. These are environment-specific and will not exist outside the MPI network.
- `output/`, `*.gif`, `*.mp4`, `*.sqlite`, and other analysis artefacts are gitignored.
- `.Renviron`, `.httr-oauth`, and other credential files are gitignored.

## Known inconsistencies to be aware of

- **Heavy runtime dependencies:** `pacman::p_load()` calls inside functions can trigger package installation at runtime. CI may need extra time, and unexpected package installations can occur in user sessions.
